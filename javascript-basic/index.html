1クレジットカードによる納付について

eL-QR、eL番号が印字されている納付書が対象です。
詳細については、納付対象の地方公共団体までご確認ください。

決済情報入力画面に表示されているお手続可能期限をご確認ください。

領収証書は発行されません。

納付日は、納付手続完了日（クレジットカード利用日）です。
ただし、納付日の「確定」は、機構指定納付受託者から地方税共同機構へお支払いされた資金が入金された日になります。

お支払手続きが完了すると、いかなる理由においても取消できません。

お支払手続きが完了すると、当サイトではいかなる理由においても支払回数の変更はできません。
支払回数の変更を希望される方は、カード裏面に記載されているカード発行会社へ直接お問い合わせください。

クレジットカード決済をご利用の際に、納付金額に応じて必要となる費用です。
システム利用料は、地方税共同機構、各地方公共団体の収入になるものではありません。

口座振替のように、一度の手続きで以後の納期分を引落しするものではありません。
納付の都度、手続きが必要です。

クレジットカードのご利用明細には下記いずれかの名称が表示されます。

なお、クレジットカード決済のシステム利用料は、合計の納付金額に対して発生します。

システム利用料は、下記サイトより試算が可能です。 システム利用料試算ページ

クレジットカード決済完了後、当社から地方税お支払サイトへ速やかにデータ連携しています。
「地方税お支払サイト」から各自治体様のデータ連携につきましては、通常何営業日で実施されているか、当社では詳細が分かりかねます。
お手数ですが地方税お支払いサイトのヘルプデスク、もしくは自治体様までご確認をお願いいたします。

解約 / 紛失 されたカードに紐づく金融機関口座より引き続きお引き落としされます。
詳細についてはご利用カード会社様までご確認ください。

地方税お支払サイトは地方税共同機構様にて運営されています。
当社はクレジットカード決済のみを提供していますので、地方税お支払サイトに関するご質問につきましては、当社では分かりかねます。

当社では詳細が分かりかねますので、ご利用のクレジットカード会社までご確認ください。

4クレジットカード納付の手順について

ご利用いただけるお支払方法は一括払い・分割払い（3回・5回・6回・10回・12回）・リボ払いです。
※分割払い・リボ払いをご利用の際は、システム利用料とは別に各カード発行会社が定める手数料が発生しますので、ご利用前にご確認ください。
※ご利用いただけるお支払方法、お支払手数料は、各カード発行会社ごとに異なります。詳しくは、ご利用のカード発行会社へ直接お問い合わせください。
※システム利用料は、分割払い・リボ払いを選択された場合においても、一括払いとなります。

カード名義人がお手続をすれば、カード名義人以外の税金でもクレジットカードで納付できます。
ただし、納付手続後は取消できませんので、トラブルにならないように事前にご確認をお願い致します。

カード発行会社により引落し日は異なります。
詳細は、カード発行会社が発行する利用明細でご確認いただくか、カード裏面に記載されているカード発行会社へ直接お問い合わせください。

お使いのブラウザの印刷機能をご利用ください。
